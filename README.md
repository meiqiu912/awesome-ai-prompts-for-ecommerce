# awesome-ai-prompts-for-ecommerce

面向电商运营、跨境卖家和客服的 AI 提示词清单。每条都是真实可打开的项目、提示词库或工具入口，覆盖选品竞品、详情页文案、商品出图、客服话术。

## 怎么用

1. 在下面找到你要干的事（写标题、做详情页、拍商品图、回客户消息……）。
2. 点开链接，复制里面的提示词。
3. 粘进任意 AI 对话框，按提示填上品类、卖点、目标人群，直接出结果。

> 本仓只做链接整理，不复制外部项目的提示词文本；提示词版权归原项目所有。
